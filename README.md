# Keepsake

**Save what matters. Find it when it matters.**

Keepsake is a self-hosted home for the links, ideas, and references you want to return to. Capture an article before it disappears into your tabs, keep a note beside a useful image or PDF, and build a library that stays yours.

Keepsake is a fork of [Karakeep](https://github.com/karakeep-app/karakeep). It builds on Karakeep's open-source foundation with additional changes and fixes.

## Make a place for what you find

- **Capture without interrupting your day.** Save links, notes, images, and PDFs from the web, browser extension, or mobile app.
- **Come back with context.** Keep page details, read saved articles, highlight useful passages, and archive pages or videos.
- **Find the right thing again.** Search your library, group items in lists, and use optional AI tagging and summaries.
- **Make it your own.** Share lists, follow RSS feeds, automate routine sorting, and connect tools through the REST API, CLI, or MCP server.

## Run Keepsake

Keepsake retains Karakeep's setup and configuration structure. Start with the [upstream installation guide](https://docs.karakeep.app/Installation/docker), [configuration guide](https://docs.karakeep.app/configuration), or [development guide](https://docs.karakeep.app/Development/setup). Those guides are maintained for Karakeep and may not describe changes specific to this fork.
