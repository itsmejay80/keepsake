A few things to know

Is Keepsake a hosted service?

Keepsake is a self-hosted application. You run it on your own infrastructure. This website introduces the project; it does not host your bookmark library.

Do I have to use AI?

No. AI tagging and summaries are optional. You can save, read, search, and organize your library without enabling AI.

How is it related to Karakeep?

Keepsake is a fork of the open-source Karakeep project. Karakeep’s cloud service, demo, mobile listings, and community channels belong to the upstream project. Visit Karakeep on GitHub to learn about the original.
